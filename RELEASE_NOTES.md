# v1.0.0-beta.1

First packaged EldenSpotter beta for Windows x64.

- Tray settings and a transparent, click-through enemy HUD.
- Hidden while unlocked; draggable preview and saved top/bottom placement.
- Health, stance-break progress, active buildup, base damage negation and status susceptibility.
- Expanded exact-handle lookup, including the Fort Faroth bat regression.

Requires an existing offline/EAC-disabled Elden Ring setup. Extract the whole ZIP before launching. This beta has mock/regression and HUD checks, plus user testing of the development build; broader live-game coverage is still welcome.
